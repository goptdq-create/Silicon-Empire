☁ Sauvegarde Google Drive

Synchronisation privée dans le dossier masqué de l'application (appDataFolder) de ton Google Drive. Le jeu ne demande pas accès à tes autres fichiers.

Le jeu doit être publié sur une adresse HTTPS autorisée dans Google Cloud. Le fichier HTML ouvert directement depuis Drive ou en file:// ne peut pas utiliser cette connexion.

Non connecté

Après connexion, les modifications sont envoyées automatiquement avec un court délai. Une autre session ouverte sur un autre appareil nécessite « Synchroniser maintenant » pour récupérer les changements ; un conflit demande confirmation. Export JSON recommandé en secours.
